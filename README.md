# Modular, Versatile, Frugal Small-Scale Agricultural Machine for Cash Crops in Nepal

![Hackathon Winner](https://img.shields.io/badge/Hackathon-Winner-brightgreen)

## Overview
This repository contains the design and documentation of our **award-winning project** from the **BE Design Hackathon 2025**. 

The project focused on developing a **modular, versatile, and frugal agricultural machine** to support small-scale farmers in Nepal cultivating **cash crops**. Our solution addresses challenges such as:

- Diverse terrains and varying soil conditions
- Dependence on manual labor
- Lack of affordable, adaptable machinery

The machine is designed for **multi-crop adaptability**, **dry and wet soil operation**, **ease of use**, and **future automation**.

---

## Key Features
- **Modular Design:** Interchangeable components for multiple cash crops like sugarcane, tea, coffee, cotton, jute, and spices.  
- **Versatility:** Functions efficiently in both dry and wet soil conditions.  
- **Frugal Innovation:** Low-cost and locally manufacturable using available materials.  
- **Ease of Use:** Simple operation suitable for small-scale farmers.  
- **Scalability:** Base design supports future automation upgrades.
